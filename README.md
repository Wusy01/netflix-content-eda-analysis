# Netflix Movies & TV Shows – Exploratory Data Analysis (EDA)
## Project Overview
Week 2 Internship Task (AnalystLab Africa) – Exploratory Data Analysis (EDA) of Netflix Movies and TV Shows dataset to identify patterns and insights related to content type, ratings, genres, release years, countries, and content added over time. The analysis was performed using Python, Pandas, Matplotlib, and Seaborn, with a focus on data cleaning, exploratory data analysis (EDA), and visualization.

## Dataset
Source: Kaggle – Netflix Movies and TV Shows Dataset

## Data Cleaning

The following steps were performed:

Handled missing values
Removed records with missing critical fields
Converted date_added to datetime
Created a year_added feature
Converted release_year to numeric
Reset the DataFrame index

## Exploratory Data Analysis

The analysis examined:

Movies vs TV Shows distribution
Content added over time
Ratings distribution
Top 10 countries represented in the dataset
Top 10 genres

## Key Findings
Movies: 69.7% of the cleaned dataset
TV Shows: 30.3%
Most common release year: 2018
Oldest release year: 1925
Newest release year: 2021
Total titles after cleaning: 8,790
Movies: 6,126
TV Shows: 2,664
TV-MA, TV-14, and TV-PG are among the most common ratings.
The United States has the highest number of country-title associations.
International Movies, Dramas, Comedies, and International TV Shows are among the most common categories.
